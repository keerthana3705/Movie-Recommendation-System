# Movie Recommendation System

This project implements a content-based movie recommendation system using Python.

The system recommends movies similar to a given movie based on textual similarity.

## Technologies Used

- Python
- Pandas
- NumPy
- Scikit-Learn

## Algorithm Used

Cosine Similarity is used to measure similarity between movie descriptions.

## Example

Input:

Avatar

Output:

- Guardians of the Galaxy
- Star Trek
- Interstellar
- Avengers
- John Carter
